How It Works

CropAI is powered by state-of-the-art vision AI models (Google Gemini, Claude, GPT-4o) accessed via OpenRouter. When you submit an image and prompt:

  • The vision model analyzes your image and returns precise pixel coordinates for the object you described.
  • Our server uses Sharp (high-performance Node.js image processing) to crop the image to those coordinates.
  • If background removal is enabled, a Python script using rembg and OpenCV performs pixel-level segmentation and edge cleanup.
  • The result is returned to you instantly, then deleted from our server within 1 hour.

Tech Stack

  • Frontend: Vanilla HTML, CSS (Glassmorphism UI), JavaScript
  • Backend: Node.js + Express
  • Image processing: Sharp (Node.js) + rembg + OpenCV (Python)
  • AI: OpenRouter → Google Gemini / Claude / GPT-4o
